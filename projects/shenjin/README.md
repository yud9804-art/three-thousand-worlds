# 《申金》· Shenjin

三千世界首个实践 IP。v0.1｜2026-10-31

## 作品介绍

一个失忆实验体从尸体处理间醒来，逃入荒漠边城。在神秘女子苏醒的帮助下，他试图查清自己的身体与身份，却逐渐进入不同势力围绕技术、寿命和秩序展开的博弈。

作品结合科幻、东方神话意象与赛博朋克环境，关注记忆、身份、人性和秩序。本公开介绍不揭示核心身份及结局。

## 两个目标

- 作品：持续完成故事，形成阅读、角色与视觉表达。
- 试点：验证清楚的创作边界、署名与原创贡献保障。

《申金》不等于三千世界全部平台。作品表现与制度验证应分别评估。
