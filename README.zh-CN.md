# 三千世界

> 让故事生长出更多世界。

[English](README.md) · [白皮书](WHITEPAPER.md) · [路线图](ROADMAP.md) · [参与指南](CONTRIBUTING.md) · [权利说明](RIGHTS.md)

**版本：v0.1.4｜日期：2026-10-31｜状态：公开讨论稿**

三千世界面向全球独立 IP 权利人与创作者，探索一种既保留各 IP 核心商业授权决策权，又支持开放共创、原创资产保障及价值回流的创作社区。

《申金》是首个实践 IP，不等于平台本身。“平行宇宙”指某个 IP 内的多线故事、不同结局和独立解读。

## 当前做到了哪里

本仓库提供初始白皮书、路线图、参与说明与《申金》试点介绍。目前没有运行多 IP 平台、分账系统、公共资金池或投票系统；具体作品许可尚未生效。

## 基本方向

- 原权利人保留 IP 权利与核心商业授权决策权。
- 非商业二创拟在项目明确公布的许可范围内开放。
- 二创者的原创贡献不因参与而自动归平台或原 IP 权利人所有。
- 官方叙事、社区评价、资金治理与商业授权分别处理。
- AI 辅助创作与运营，人承担权利、资金及规则决策责任。

公开仓库不等于作品全部开源；当前授权状态见[权利说明](RIGHTS.md)。本版本不是最终许可或收益分配协议。

## 如何参与

先读[参与指南](CONTRIBUTING.md)，再通过 [Issues](https://github.com/yud9804-art/three-thousand-worlds/issues) 提交规则问题、修改建议、翻译意向或试点参与意向。不需要会编程。

普通读者可以从[《申金》介绍](projects/shenjin/README.md)了解作品，无须先理解全部制度。正式阅读入口与可用素材包待发布。

## 创作重心

以作品为核心，允许不同解读，尊重原作创作自主权与参与者的原创贡献。其他独立世界不必接受《申金》的设定或结论。当前聚焦故事、可授权资源与简单公开入口。

详见[创作方向与开放边界](docs/CREATIVE_DIRECTION.md)。

## 独立站点协作

各 IP 可独立运营站点，自愿参与共享计划。共享池、贡献评价及分周期票制尚待验证，详见[协作与治理方案](docs/COOPERATION_AND_GOVERNANCE.md)。当前没有部署区块链或运行会员票制。

## 拟议服务

入口以导航与合作信息为主；任务制合作、商业使用协调及维权支持的范围与启动条件见[轻量入口与任务协作](docs/SERVICES_AND_TASKS.md)。这些服务尚未运行，不承诺接单收入或诉讼资助。

## 近期重点

公开文档首版已完成，主要精力转向《申金》创作与推广，平台以实际反馈和试点所需的维护为主。读者入口聚焦故事，创作者入口聚焦资料、许可与合作。功能增加条件见[路线图](ROADMAP.md)。试点人数、周期及指标尚未确定。
